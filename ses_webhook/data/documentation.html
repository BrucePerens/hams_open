SES Webhook Functionality

This module provides an interface to configure incoming email routing from Amazon SES via Amazon SNS (Simple Notification Service) webhooks.

UI Functionality

1. SES Webhook Domains

Path: SES Webhooks > Domains

  • List View: Displays configured domains, their associated company, and the Webhook URL.
  • Form View: Allows administrators to register a new domain and map it to a tenant company.
    • Secret Token: Automatically generated and used to authenticate requests -- one of two independent checks; incoming requests are also required to carry a real, verified AWS SNS message signature. The token is part of the Webhook URL (its token query parameter), so keep that URL private.
    • Webhook URL: The URL to provide to Amazon SNS. It can be easily copied to the clipboard.
    • AWS Configuration Instructions: A dedicated tab providing step-by-step guidance on setting up the Amazon SNS Topic and Amazon SES Receipt Rule.

2. SES Webhook Logs

Path: SES Webhooks > Logs

  • List View: Shows a color-coded log of all received webhooks. Green for success, red for failed, and gray for ignored. The two rejection statuses (Rejected Subscribe URL, and Rejected: Invalid AWS SNS Signature) have no color.
    • Ignored means the request was accepted but no incoming email was handed to Odoo's mail processing: an unsubscribe confirmation, a notification with no email content, or an email from a sender with no matching user account (see Pending Submissions below).
    • Rejected Subscribe URL means a subscription confirmation named a confirmation address that is not an Amazon SNS address, so it was not visited.
    • A request with a missing or wrong token is refused and does not appear in this log.
  • Form View: Displays detailed information about a specific webhook request, including:
    • Message ID, Date, Payload Type, and Status.
    • Raw Payload: The original JSON payload received from SNS.
    • Error Message: Displayed if the webhook failed to process.

3. Pending Submissions

Path: SES Webhooks > Pending Submissions

When an incoming email's sender does not match any user account, the email is not handed to Odoo's mail processing. It is held here instead, and the sender is sent an email asking them to create an account with the same address and then resend their message. Held emails are deleted automatically 7 days after they arrive.

4. Bounces and Complaints

Amazon SES bounce and complaint notifications arriving at the same webhook add the affected recipient addresses to Odoo's email blacklist, so no further mail is sent to them. Every spam complaint is blacklisted; a bounce is blacklisted only when Amazon SES reports it as permanent.

Logs older than 30 days are automatically deleted by a scheduled action to preserve database space.
