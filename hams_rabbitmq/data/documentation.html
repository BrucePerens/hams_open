RabbitMQ Global Connection Pool

The hams_rabbitmq module provides a secure global connection pool for RabbitMQ. This feature operates entirely in the backend and serves as an integration backbone for other services.

Note for Administrators: The RabbitMQ user, password, port and virtual host are read from the Odoo system parameters rabbitmq.user, rabbitmq.pass, rabbitmq.port and rabbitmq.vhost through zero_sudo's whitelisted parameter reader; unset values fall back to guest / guest, port 5672 and virtual host /. The broker host comes from the RABBITMQ_HOST environment variable (default rabbitmq). There is no direct configuration menu for RabbitMQ.

The "pool" is one shared connection and channel that every module reuses. Messages are sent only after the database transaction that queued them commits; a message that cannot be sent (no connection, or the send fails) is logged and dropped, not retried.
