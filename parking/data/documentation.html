Parking domains

One Odoo instance answers for many domains. Open Parking > Domains (reachable only from the server itself, through an SSH tunnel to the instance's loopback port) and add a domain with one of four behaviours: a parked page, a 301 or 302 redirect to a fixed URL, a for-sale page with a contact form (inquiries appear under Inquiries), or 410 Gone.

What visitors see

  • A small self-contained page (a few kilobytes, no scripts, no cookies). robots.txt and X-Robots-Tag ask search engines not to index it unless you switch that off per domain.
  • A host that is not in the list gets a plain 404 (setting parking.unknown_host_policy: not_found or default_page).
  • Nothing else is served from the internet: the Odoo login, backend, JSON-RPC and websocket routes answer 404 on every public host.

Bulk changes

Use parking_ctl.py (hams_shared/tools) with a text file of domains: it validates, shows a dry-run, and creates the records.
