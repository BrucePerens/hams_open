# radioctl-capi

The C ABI of radioctl, a sketch (ABI version 1). Build it with `cargo build -p radioctl-capi`; the
library is `libradioctl_capi.so` (and a static library), the header is `include/radioctl.h`,
generated by cbindgen from `src/ffi.rs` (a test fails if the checked-in copy is out of date).
Rules, in short: explicit runtime ownership, the transmit gate closed until the explicit permit
call, no panic across the boundary, no raw command. Manual: `docs/manual/14-station.md`, "The C
ABI". This is the only crate in the workspace with `unsafe`; it is confined to `src/ffi.rs`.

## Using it from C

```c
#include "radioctl.h"
rctl_runtime *rt = NULL;
rctl_rig *rig = NULL;
if (rctl_runtime_new(&rt) != RCTL_OK) { /* rctl_last_error() says why */ }
if (rctl_rig_open_tcp(rt, rigfile_text, "192.168.1.50:4992", &rig) == RCTL_OK) {
    uint64_t hz;
    rctl_rig_get_frequency(rig, 0, &hz);   /* works with the transmit gate closed */
    /* rctl_rig_set_ptt(rig, 1) returns RCTL_ERR_TX_GATE_CLOSED until
       rctl_rig_permit_transmit(rig, "who decided") */
    rctl_rig_close(rig);                   /* unkeys first */
}
rctl_runtime_free(rt);                     /* RCTL_ERR_BUSY while a rig or rotator is still open */
```

Rotators (the engines of `radioctl-station`: rotctld and GS-232, models from `data/station/rotators.toml`):
`rctl_rotator_open_virtual`, `_open_tcp` and `_open_serial` take a model id such as
`yaesu-g-5500-gs232b`; then `rctl_rotator_set_position` (outside the model's travel is refused with
`RCTL_ERR_REJECTED` before anything is written), `_get_position`, `_stop`, `_park` and
`rctl_rotator_close`. Nothing is verified against a real rotator.

Link with `-lradioctl_capi`; the working example is `tests/c/capi_test.c`. Every call returns a
negative `RCTL_ERR_*` code on failure and sets a per-thread message read with `rctl_last_error()`.
