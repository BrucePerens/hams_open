# Glasgow install: dependency record (2026-11-08)

What `install_glasgow.py` installs, from where, at which version, and under which licence. Nothing here is vendored into the repository and
nothing is installed into another venv: the packages go into one directory the bench server manages (`~/.local/share/bench_mcp/glasgow-70cb38c9`).
`requirements.txt` carries the sha256 of every Linux wheel and sdist of each version (`pip install --require-hashes --only-binary=:all:`); it is
generated by `pin_requirements.py` from PyPI's own JSON, which a person re-runs when bumping a pin.

Not installed on purpose: `yowasp-nextpnr-ecp5` (166 MB, needed only for revision D), the optional `http`, `numpy` and `qt` extras, and any
vendor binary. ECP5 can be added by a person: `<install>/venv/bin/pip install yowasp-nextpnr-ecp5==0.11.1.0.post826` after checking its hash.

Measured on the dev box (32 cores, `nice -n 10`): install 8 s with the archive on disk (about 20 s with downloads), 552 MB on disk; gateware builds 4 to
15 s per applet configuration, 135 kB each in the cache.

The device is flashed by nobody here: the software loads its own firmware into the device's RAM on each connection (`glasgow flash` is never run).
