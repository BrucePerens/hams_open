# RX-888 MkII HF receiver

The `bench_rx888_*` tools run an RX-888 MkII through ka9q-radio's `radiod` on this machine's loopback interface. They can load the firmware, start and stop `radiod`, read the front end, measure a channel, take a spectrum and record I/Q or audio. Nothing here transmits. Start with the overview, then setup.
