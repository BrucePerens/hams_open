# DG8SAQ VNWA 3E vector network analyser

A USB vector network analyser (DG8SAQ VNWA 3E) driven through the `vnwa_open` crate: its USB control interface and its two USB audio codecs, with no vendor software. The tools measure S21 and S11 as raw ratios (calibration is a separate, optional step), run the signal generator and the frequency meter, and recover the unit when it stops answering.
