# Glasgow Interface Explorer

`"driver": "glasgow"`: the Glasgow Interface Explorer (1BitSquared, USB 20b7:9db1) with 16 level-shifted I/O pins on two ports, A and B. Start with [overview](instruments/glasgow/overview), then [setup](instruments/glasgow/setup) and the [bench session](instruments/glasgow/bench-session) for anything that needs wiring.
