# radioctl rigs (receivers and dummy-load transmitters)

The `bench_radioctl_*` tools. A rig is any radio radioctl has a description for, reached through the `radioctld` daemon. Start with the overview, then setup (the config entry, which tier to give the rig) and limits (what the safety model can and cannot know).
