# Instruments

One directory per kind of instrument (not per alias: the aliases in the configuration are site-specific, see [configuration](concepts/configuration)). A directory holds, where they apply: `overview` (what it is, the specifications that matter, connectors), `setup` (cabling, power, safe levels, the configuration entry), `operation` (every function with step-by-step procedures), `measurement-recipes` (worked examples with expected results), `limits` (ranges, accuracy, quirks, what is not verified), `troubleshooting` (symptom, cause, action) and `protocol` (the wire protocol in short, pointing at the crate docs).
