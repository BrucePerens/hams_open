# bench_usb_topology

The USB tree from sysfs with per-device speed, power, drivers and nodes.

Arguments: `device` (path or port label; that device and everything below it), `bus`, `flat`. No privilege needed.

See the USB hub pages for the verification levels and the protection rules.
