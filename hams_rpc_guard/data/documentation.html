RPC Guard

Odoo can be called by other programs through three generic interfaces: XML-RPC (/xmlrpc), JSON-RPC (/jsonrpc) and JSON-2 (/json/2). RPC Guard makes the first two answer only programs running on the same computer as Odoo, and lets you do the same for JSON-2.

Settings

Open Settings, Technical, System Parameters. Nothing needs to be set: the defaults are the safe ones.

  • hams_rpc_guard.legacy_access: loopback (default), any or none. Controls XML-RPC and JSON-RPC.
  • hams_rpc_guard.json2_access: any (default), loopback or none. Controls JSON-2. Set it to loopback when every program that calls Odoo runs on this computer.
  • hams_rpc_guard.trusted_proxies: addresses of a reverse proxy on this computer that may pass on requests from local programs. Usually empty.

What a refused caller sees

A plain "not found" page, as if the interface did not exist. The server log counts refusals (never addresses or request contents).

Your own programs

A program on this computer that calls http://127.0.0.1:8069 directly keeps working. A program that goes out through your public address, and so through your web proxy, is treated as a visitor.
