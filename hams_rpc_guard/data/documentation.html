RPC Guard

Odoo can be called by other programs through three generic interfaces: XML-RPC (/xmlrpc), JSON-RPC (/jsonrpc) and JSON-2 (/json/2). RPC Guard makes them answer only programs on networks you allow, by default only programs running on the same computer as Odoo.

Settings

Open Settings, Technical, System Parameters. Nothing needs to be set: the defaults are the safe ones. A value that is not valid cannot be saved.

  • hams_rpc_guard.allowed_networks: the networks whose programs may call Odoo, for example 127.0.0.0/8,::1/128,10.99.0.0/24. Default: this computer only.
  • hams_rpc_guard.legacy_access: none switches XML-RPC and JSON-RPC off entirely.
  • hams_rpc_guard.trusted_proxies and hams_rpc_guard.client_address_header: a reverse proxy you run, and the header it sets to the caller's address. Usually empty.
  • hams_rpc_guard.rpc_transport: tcp (default), unix (only through the local socket) or both; hams_rpc_guard.unix_peers lists the computer accounts that may use the socket. The socket itself is set up in the server configuration file (see the module's README).
  • hams_rpc_guard.mode: report refuses nothing and only counts what would be refused.

What a refused caller sees

A plain "not found" page, as if the interface did not exist. The server log counts refusals by kind of network (never addresses or request contents).

Your own programs

A program on this computer that calls http://127.0.0.1:8069 directly keeps working. A program that goes out through your public address, and so through your web proxy, is treated as a visitor. Your browser's own use of Odoo is not affected.
