☁️ Cloudflare Edge Orchestration (cloudflare)

The Cloudflare Edge Orchestration module is your central command center for managing Cloudflare's CDN (Content Delivery Network, Cloudflare's worldwide edge cache) and Web Application Firewall (WAF). Fully optimized for Odoo 19, it automates caching, security, and connectivity between your Odoo server and the Cloudflare edge, significantly improving performance and security for one or many websites while maintaining strict Zero-Trust security standards.

1. Getting Started

To begin, you need to connect Odoo to your Cloudflare account. Navigate to Settings > Cloudflare and look for the Cloudflare Edge Orchestration section. Configuration is website-specific, allowing you to manage multiple domains independently.

  • CF API Token: This is a secure token you create in your Cloudflare dashboard. It must have permissions for Zone.Cache Purge, Zone.Firewall Services, and optionally Account.Cloudflare Tunnel.
  • CF Zone ID: This unique ID identifies your domain in Cloudflare. You can find it on your domain's overview page in the Cloudflare dashboard.
  • CF Account ID: Your main Cloudflare account ID, required if you want to use Zero Trust Tunnels.
  • Turnstile Secret: Optional. The secret key of your Cloudflare Turnstile widget, needed only if your forms use Turnstile.

2. Making Your Site Fast: Cache Management

This module uses Cloudflare to store copies of your website content around the world, so it loads instantly for users everywhere.

  • Smart Caching: Odoo automatically tells Cloudflare how long to keep different types of content. Odoo's bundled stylesheets and scripts (served under /web/assets) are cached for a year, while public website pages that opt in are cached for 24 hours for visitors who are not logged in. Images and file downloads served by /web/image and /web/content are never cached at the edge, because they can be private.
  • Automatic Updates: When you edit or delete a page, blog post, or product, or edit a website menu, Odoo automatically tells Cloudflare to clear the old version from its cache. Page, post, and product changes clear individual URLs, while menu changes trigger a full website cache refresh to ensure headers and footers are updated immediately. This all happens in the background (a queue processed every minute), ensuring your visitors always see the latest content without slowing down your work. If a website has no API Token or Zone ID, its queued clears are marked failed and are not retried.
  • Static File Sync: The module contains a check that compares your module files' modification times with the last recorded one and, if any are newer, clears the static-asset cache (the odoo-static-assets tag) on all your websites. Nothing currently runs this check when the server starts, so after updating theme or module files you can clear that tag yourself with the Manual Cache Purge wizard below.
  • Manual Control: If you ever need to clear the cache manually, you can use the wizard under Cloudflare Edge > Manual Cache Purge. You can clear everything, specific pages, or groups of content using tags (labels Odoo attaches to cached responses, such as odoo-static-assets or odoo-website-1).

3. Keeping Your Site Secure: Firewall & IP Bans

Protect your Odoo instance from bots and attackers using Cloudflare's security edge.

  • Honeypot Protection: The module provides the ban service that silent "honeypot" traps in other modules call; it does not contain a trap itself. When a malicious bot triggers such a trap, its IP address is banned at the Cloudflare network level with an IP Access Rule on that website's zone. A ban has no expiry: it stays until you lift it. You can review these bans under Cloudflare Edge > Honeypot Triggers (Bans), where Lift Ban removes the rule from Cloudflare. A ban that could not be sent to Cloudflare (for example, missing credentials) is shown as API Sync Failed.
  • Firewall Rules (WAF): You can manage advanced Cloudflare firewall rules directly from Odoo. The rules are listed under Cloudflare Edge > WAF Rulesets. In Settings > Cloudflare, Pull from Edge replaces this website's rules in Odoo with the zone's current custom firewall rules, and Push to Edge replaces the zone's whole custom firewall ruleset with the rules in Odoo, so a rule that exists only in Cloudflare is removed.
  • Security Level: Quickly adjust how aggressive Cloudflare's security should be (e.g., enabling "Under Attack" mode if you are experiencing a surge of malicious traffic) using the Zone Settings Wizard under Cloudflare Edge > Zone Settings, which also sets Development Mode and the browser cache TTL. Changes are applied to Cloudflare immediately.

4. Secure Connections: Zero Trust Tunnels

Cloudflare Tunnels allow you to host your Odoo server securely without opening any ports on your firewall. This creates a private, encrypted "tunnel" between your server and Cloudflare.

  • Easy Setup: Use the Generate Setup Command button in Settings > Cloudflare (it needs the API Token and Account ID). Odoo will create the tunnel in Cloudflare and give you a simple cloudflared service install ... command to run on your server.
  • Management: View the health and status of your tunnels under Cloudflare Edge > Tunnels. You can sync the list from Cloudflare or delete tunnels directly from the Odoo interface.

5. Advanced Integration & Security

For developers and advanced users, the module provides several tools designed for high security and performance:

  • Geographic Data: The module extracts location information (Country, City, etc.) provided by Cloudflare for every request. It is trusted only when the request comes through your local Cloudflare Tunnel or, if an administrator has turned on Trust Cloudflare's Published IP Ranges (Settings > Cloudflare, for a site with no Tunnel), from an address in that trusted range list; otherwise the location fields are left empty, so a request sent straight to your server cannot fake them. This data is handled safely even in background tasks where a standard web request might not be present.
  • Turnstile CAPTCHA: Securely verify Cloudflare Turnstile tokens on your public forms to prevent spam. Without a Turnstile Secret in the settings, every token is rejected.
  • Safe Caching: Sensitive areas like your shopping cart, checkout, and portal pages, and every page shown to a logged-in user, are automatically excluded from edge caching to protect user privacy.

6. DNS & Custom Hostnames

  • DNS Records Management: Keep a list of DNS records under Cloudflare Edge > DNS Records. Changing a row does not change your live DNS until an administrator pushes it: a push shows a plan first, and applies exactly that plan. It creates and updates only the records Odoo has a row for, and deletes nothing except a record whose row is marked Retire.
  • Custom Hostname Provisioning: Allows multi-tenant setups where customers can bring their own domains. When a custom domain is added whose name matches one of your websites' domains, and that website has an API Token and Zone ID, Odoo automatically provisions the Custom Hostname in Cloudflare and requests its SSL certificate. Otherwise no hostname is created. If Cloudflare refuses to delete a hostname when its domain is removed, the domain is still removed in Odoo and the hostname is listed under Cloudflare Edge > Pending Hostname Deletes for automatic retries.

7. Advanced Traffic & Security Controls

  • Analytics Dashboard: A dashboard intended to show Cloudflare traffic, security events, and performance metrics within Odoo. It is currently a placeholder that displays fixed sample numbers, not your real Cloudflare data.
  • Rate Limits & Cache Rules: Record rate limiting policies and custom cache rules in Odoo. They are stored in Odoo only and are not sent to Cloudflare, so they take effect only once you configure them in Cloudflare itself.
  • Zero Trust Policies: Record Cloudflare Zero Trust policies for specific routes and internal applications. Like rate limits, they are stored in Odoo only and are not deployed to Cloudflare.
  • Configuration Backups: When the module is installed, it saves a read-only "Pre-Odoo Backup" of each website's existing Cloudflare custom firewall rules (the rules as they were before Odoo took them over) and then imports those rules into Odoo. Backups are listed under Cloudflare Edge > Configuration Backups. No backup is made before later pushes, and there is no restore button; a backup shows the raw rules for reference.
