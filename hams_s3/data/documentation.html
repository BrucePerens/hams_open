Cloud Storage Configuration

The hams_s3 module adds a dedicated Cloud Storage block to Odoo's General Settings (Settings > General Settings) for configuring an Amazon S3 (Simple Storage Service) storage backend. The AWS (Amazon Web Services) fields below hold its connection settings.

Configuration Fields

  • Use Amazon S3 Storage: Enables the S3 backend. The fields below appear only while this box is checked and the OCA (Odoo Community Association) storage_backend addon is installed. While that addon is missing, a warning alert is displayed instead, directing the administrator to run the setup script hams_s3/scripts/install_oca_storage.py, which takes the destination addons directory as a required argument. Saving with this box checked writes the values below to the first storage.backend record of type amazon_s3, creating one named "Amazon S3 Storage" if none exists; saving with it unchecked does not touch that record.
  • AWS Host: The endpoint URL for the S3-compatible service (leave blank for default AWS).
  • AWS Access Key: The Access Key ID for authentication.
  • AWS Secret Key: The Secret Access Key for authentication. The field is masked as a password.
  • AWS Bucket: The name of the S3 bucket to store attachments.
  • AWS Region: The geographic region of the bucket, chosen from a fixed list (e.g., us-east-1) or "Other". If left empty, us-east-1 is saved.
